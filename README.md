# Лабораторная работа №5. Контейнеры-адаптеры STL (C++)

Проект по курсу ООП (Вариант 10). Консольное приложение для учета и диспетчеризации строительной техники в строительной компании (ООО «СтройТехИнвест»).

В работе на практике показано применение трех контейнеров-адаптеров стандартной библиотеки C++ (STL): `std::queue`, `std::stack` и `std::priority_queue`.

---

## Задачи и назначение контейнеров

В предметной области учета техники каждый контейнер отвечает за свой сценарий:

1. **Плановая очередь заявок (`std::queue`, FIFO)**
   - Заявки прорабов на выделение техники обрабатываются в порядке их поступления: первая пришедшая заявка первой идет в работу.
   - Основные операции: добавление заявки в конец (`push`), просмотр первой машины (`front`), отправка техники на объект (`pop`).

2. **Журнал возврата техники (`std::stack`, LIFO)**
   - Фиксация техники, возвращающейся со строительных площадок на базу обслуживания. Последняя вернувшаяся машина первой идет на осмотр и техобслуживание.
   - Используется также для отката ошибочных распределений. Основные методы: `push`, `top`, `pop`.

3. **Аварийные и приоритетные вызовы (`std::priority_queue`, куча / Heap)**
   - Распределение техники при срочных вызовах и авариях. Элементы извлекаются не по порядку добавления, а по заданному критерию важности.
   - Поддерживается переключение четырех режимов сортировки (по уровню аварийности, по часовой ставке аренды, по отработанным моточасам и по инвентарному номеру).

---

## Особенности реализации

- **Почему именно адаптеры, а не обычные векторы:** адаптеры намеренно скрывают прямой доступ по индексам и итераторы. Это гарантирует, что порядок обслуживания (FIFO или LIFO) нельзя случайно нарушить из клиентского кода.
- **Просмотр данных без разрушения очереди:** поскольку у адаптеров нет итераторов `begin()` / `end()`, для вывода таблицы на экран и экспорта в файл создается локальная копия контейнера, из которой элементы считываются и снимаются через `pop()`. Исходные данные в программе при этом полностью сохраняются.

## Структура проекта

```text
lab5/
├── EquipmentRecord.h / .cpp  – класс единицы техники (ID, модель, госномер, объект, ставка, моточасы, приоритет)
├── Comparators.h              – структуры-компараторы для сортировки в priority_queue
├── AdapterManager.h / .cpp   – управляющий класс (работа с тремя контейнерами, поиск, фильтры, экспорт)
├── Input.h                   – безопасный ввод чисел и строк с проверкой ошибок
├── main.cpp                  – консольное меню и логика программы
├── lab5.vcxproj              – проект для Visual Studio 2022
└── README.md                 – описание лабораторной работы
```

---

## Основные возможности программы

- Интерактивное текстовое меню для каждого из трех контейнеров;
- Просмотр содержимого в виде аккуратной таблицы;
- Добавление новой техники с проверкой вводимых значений;
- Извлечение текущей машины из очереди или со стека;
- Редактирование и удаление записей по инвентарному номеру (ID);
- Поиск техники по марке или названию строительного объекта;
- Фильтрация по категории работ (земляные, грузоподъемные, дорожные и т.д.);
- Смена критерия сортировки в приоритетной очереди;
- Сохранение общего отчета по всем контейнерам в текстовый файл;
- Быстрое заполнение тестовыми данными для демонстрации.

## Сборка и запуск

Проект написан на C++17 и собирается в Visual Studio 2022.

### Сборка через Visual Studio:
Открыть файл `lab5.vcxproj` в Visual Studio 2022 и нажать **Сборка -> Собрать решение** (Ctrl+Shift+B).

### Сборка через командную строку (Developer Command Prompt):
```cmd
cd lab5
msbuild lab5.vcxproj /p:Configuration=Release /p:Platform=x64
..\x64\Release\lab5.exe
```

Либо напрямую через компилятор MSVC:
```cmd
cl /std:c++17 /EHsc *.cpp /Fe:lab5.exe
lab5.exe
```
